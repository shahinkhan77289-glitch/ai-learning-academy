অভিভাবক রিপোর্ট ও রিমাইন্ডার চালু করতে পরের ধাপে নিরাপদ backend/API
এবং আরও development প্রয়োজন।

Home Screen-এ ইনস্টল:
1. HTTPS-এ হোস্ট করতে হবে (যেমন GitHub Pages-এর মতো ফ্রি static hosting)।
